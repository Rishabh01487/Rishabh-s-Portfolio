# Rishabh Gupta — AI & ML Engineer Portfolio

A modern, animated portfolio website built with vanilla HTML, CSS, and JavaScript.

## 🚀 Live Demo

Deployed on Vercel: [View Portfolio](https://rishabh-s-portfolio.vercel.app)

## ✨ Features

- Animated splash screen with smooth transitions
- Custom cursor with interactive hover effects
- Responsive design for all screen sizes
- Dynamic typing animation in the hero section
- Smooth scroll-reveal animations
- Interactive project cards
- Contact form with mailto integration
- Floating orb background effects with glassmorphism

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, animations, grid, flexbox
- **JavaScript** — Vanilla JS for interactions and animations
- **Google Fonts** — Clash Display & DM Sans

## 📦 Local Development

```bash
# Clone the repository
git clone https://github.com/Rishabh01487/Rishabh-s-Portfolio.git

# Navigate to the project
cd Rishabh-s-Portfolio

# Serve locally (requires Node.js)
npx serve . -p 3000
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment

This project is configured for **Vercel** deployment:

1. Push to GitHub
2. Import the repository on [vercel.com](https://vercel.com)
3. Vercel will auto-detect the static site and deploy

### Vercel Configuration

The `vercel.json` file includes:
- Static file serving
- Security headers (X-Content-Type-Options, X-Frame-Options, etc.)
- Asset caching for optimal performance
